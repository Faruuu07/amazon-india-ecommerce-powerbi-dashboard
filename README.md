# 📊 Amazon India E-Commerce Sales & Operations Dashboard

An interactive **Power BI dashboard** designed to analyze Amazon India e-commerce sales, orders, customers, products, payments, and operational performance.

## 🎯 Project Overview

This project transforms e-commerce sales data into an interactive business intelligence dashboard using **Microsoft Power BI**.

The dashboard helps analyze revenue performance, order trends, customer activity, product performance, payment methods, order status, and geographic sales distribution.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Star Schema
- Interactive Visualizations
- Slicers & Filters

## 📌 Key KPIs

- 💰 **Total Revenue:** ₹92M
- 🛒 **Total Orders:** 100K
- 👥 **Total Customers:** 43K
- 💵 **Average Order Value:** ₹918
- 🔄 **Return Rate:** 3.05%

## 📊 Dashboard Features

- Revenue analysis by year and month
- Revenue analysis by state
- Revenue analysis by product
- Revenue analysis by category
- Order status analysis
- Payment method analysis
- Customer analysis
- Interactive Year, State, Category and Payment Method slicers
- Date-range filtering
- Dynamic KPI cards

## 🧩 Data Model

The dashboard uses a dimensional data model containing:

- `fact_sales`
- `dim_customer`
- `dim_date`
- `dim_product`
- `dim_location`

Relationships were created between the fact and dimension tables to support efficient filtering and analysis.

## 📈 Business Insights

The dashboard enables users to identify:

- Overall revenue and order performance
- Top-performing states
- Highest-revenue products
- Category-wise revenue contribution
- Customer and order trends
- Payment method distribution
- Order status distribution
- Return-rate performance
